## 本機觀看
解壓縮後雙擊 index.html 即可觀看，無須安裝套件。

## 上傳 GitHub Pages
1. 登入 https://github.com/new ，建立公開儲存庫（例如 sculpture-gallery）。
2. 選擇 Add file → Upload files。
3. 將本資料夾內所有檔案及 images 資料夾拖進上傳區。index.html 必須位於儲存庫最外層。請勿只上傳 ZIP。
4. 按 Commit changes。
5. Settings → Pages → Build and deployment 選 Deploy from a branch。
6. Branch 選 main，資料夾選 / (root)，按 Save。
7. 等待 GitHub 顯示網站網址，即可開啟分享。

修改文字請編輯 works.js；更換照片請替換 images 內的對應檔案。
所有樣式、圖片與程式均在本資料夾，不需外部服務。

## 中英日文版
右上角可切換繁體中文、English、日本語，並記住上次選擇。也可在網址後加 ?lang=en 或 ?lang=ja 直接分享指定語言。每件作品的標題、說明、分類及網站介面皆有三語版本。翻譯存於 works.js，介面文字存於 i18n.js。
